# SCD Analysis Studio

Single-Case Experimental Design（SCD）の視覚分析と非重複指標を，一般的なWebブラウザで実行する静的Webアプリケーションです．研究データはブラウザ内で処理し，アプリケーション側のサーバーへ自動送信しません．

## 1. 画面構成

1. Excel／CSVファイルと，Excelの使用シートを選択します．
2. データビューで列名，行番号，セル値，列型，欠損・非数値候補を確認します．マウスドラッグまたは `C2:C6` 形式で範囲指定できます．
3. 視覚分析では，時間列・フェーズ列・データ列・解析方法を選択します．A1とA2，B1とB2など，同じ元フェーズ記号は初期状態で同色です．
4. グラフ右上の「ダウンロード」から，PNG，JPEG，WebP，SVGと，画像の幅・高さを指定して保存できます．Plotly標準の操作ツールバーは表示しません．
5. 統計解析では，データビューの右側に解析データ登録欄を並べ，最大4範囲を登録します．2範囲を選択してPND，NAP，Tau／Tau-Uを計算します．
6. 結果表示は，主要な推定値・判定・計算確認に必要な値を優先し，同じ内容を表す重複項目を省いています．Tau-Uの詳細な計算過程は折りたたみ表示です．

```

```

## 4. 共通仕様

- 内部計算では丸めず，画面表示時のみ指定桁数へ丸めます．
- 空欄，欠損，数値化できない値は除外します．
- 記述統計量および2SD法の標準偏差は標本標準偏差（分母 `n−1`）です．
- フェーズは文字を一括統合せず，時間順の連続区間で `A1, B1, A2, B2` のように分割します．
- 視覚分析の2SD法，Celeration Line分析，VAIORでは改善方向を選択できます．
- 統計解析は入力値を反転せず，B期がA期より大きい比較を正方向として扱います．
- 縦軸の最小値・最大値・目盛間隔を任意に指定できます．空欄ではPlotlyの自動設定を使用します．
- グラフの目盛線は表示・非表示を切り替えられます．

## 5. 視覚分析の計算仕様

### Trend（最小二乗法）

```text
Slope = Σ[(xi−x̄)(yi−ȳ)] / Σ[(xi−x̄)^2]
Intercept = ȳ−Slope×x̄
Ŷ = Intercept＋Slope×X
```

### Trend（Theil–Sen法）

```text
Slope = median{(yj−yi)/(xj−xi) | i<j, xj≠xi}
Intercept = median(yi−Slope×xi)
```

同一Xの組み合わせは除外します．

### 2SD法

ベースライン期の平均を中心として，標本標準偏差の2倍を上下に加減した水平帯を介入期まで延長します．

```text
上限線 = Mean(A)＋2×SD(A)
下限線 = Mean(A)−2×SD(A)
```

結果には，A期平均，SD，2SD，上限，下限，改善側境界を超えたB期データ数・割合を表示します．境界線と同じ値は，境界を越えたデータに含めません．

### Celeration Line

A期のデータを時間順に前半・後半へ分割し，各群のX中央値とY中央値から作成した2座標を結びます．奇数点の場合は中央点を前半と後半の両方に含めます．求めたCeleration Lineを直後のB期へ延長し，B期の実測値が改善方向側に位置する点数を数えます．線上の点を除外したうえで，改善方向に位置する点が偶然の50％を上回るかを正確片側二項検定で確認します．

### VAIOR

1. A期にTheil–Senトレンドを当てます．
2. `|実測値−予測値|` の中央値を変動幅とします．
3. `Trend±絶対偏差中央値` をB期へ投射します．
4. 即時効果はB期最初の3点，漸進的・遅延的効果はB期最後の3点で判定します．
5. 判定基準値は `2×A期範囲外割合` です．
6. B期改善側範囲外割合が判定基準値を上回る場合に，介入期全体を効果ありとします．

「基準値の生値」と「判定に用いた基準」は同一内容であるため，結果には**判定基準値**として一つだけ表示します．値が1を超えた場合は，B期割合では到達不能であることを併記します．

## 6. 統計解析の計算仕様

### PND

```text
PND = #(B > max(A)) / nB
```

結果にはA期最大値，超えたB期データ数，PNDを表示します．同値は非重複に含めません．表示上の目安は，50％未満＝効果なし，50～69％＝判断保留，70～89％＝効果あり，90％以上＝非常に大きい効果です．これは便宜的な区分であり，視覚分析と併せて解釈します．

### NAP

```text
NAP = [#(B>A)＋0.5×#(B=A)] / (nA×nB)
```

結果にはNAP，90％CI，95％CI，P値，ペア内訳を表示します．標準誤差はSen–Meeの不偏分散推定，信頼区間はNewcombeのscore-inversion法，P値は同順位補正を含むMann–Whitney Uの正規近似です．目安は，0.50未満＝B期が低い方向，0.50＝方向差なし，0.50超～0.65＝弱い変化，0.66～0.92＝中程度，0.93～1.00＝強い変化です．

### Tau

```text
S_AB = #(B>A)−#(B<A)
Tau = S_AB / (nA×nB) = 2×NAP−1
```

Tauの標準誤差と信頼区間はNAPを `2×NAP−1` で線形変換し，P値はNAPと同じMann–Whitney U近似を用います．符号は方向，絶対値は大きさを表します．絶対値の目安は，0.20未満＝小さい，0.20～0.59＝中程度，0.60～0.79＝大きい，0.80以上＝非常に大きい変化です．

### Tau-U

「ベースラインで補正する」を選択した場合に算出します．

```text
S_A = A期内の時間順ペアについて #(後値>前値)−#(後値<前値)
Tau-U = (S_AB−S_A) / (nA×nB)
```

主結果はTau-U，90％CI，95％CI，P値です．`A–B Tau`，`ベースライン期Tau`，`S_AB`，`S_A`，代入式は「計算過程を表示」を開いた場合だけ表示します．効果量の目安はTauと同じく絶対値で示します．Tau-Uの標本分布は十分に確立していないため，信頼区間とP値は，A期を逆時系列化しB期を同順位化したKendall Sの同順位補正付き正規近似による参考値です．補正量によって点推定や信頼区間が−1～1を超える場合も，値を切り詰めません．

## 7. グラフ画像の保存

グラフ右上の「ダウンロード」を押し，次を指定します．

- 画像形式：PNG，JPEG，WebP，SVG
- 幅
- 高さ
- 縦横比を維持するか

指定したピクセル数でPlotlyの画像を書き出します．SVGはベクター形式ですが，幅と高さは出力キャンバスの寸法として使用されます．

## 8. 自動テスト

```bash
cd scd-analyzer

```

現在のテスト項目は29件で，すべて成功しています．既知の計算例，同値，欠損，方向反転，境界値，奇数・偶数データ，フェーズ分割を含みます．

## 9. 制約・注意点

- データビューは最大5,000行を表示しますが，解析には読み込んだ全行を使用します．
- 時間列は数値として解釈できる必要があります．
- 端末に存在しないフォントはブラウザの代替フォントで表示されます．
- 小標本のCI・P値は不安定になり得ます．特にTau-UのCI・P値は参考値として扱ってください．
- 視覚分析および非重複指標は，研究者によるグラフの総合的な視覚分析を置き換えるものではありません．
- 代表データについて，手計算または独立したソフトウェアと照合してから研究利用してください．
